# Patchipulusu Leela Krishna Raghavendra - Portfolio

A world-class, fully responsive personal portfolio website showcasing my experience as a Software Engineer (Backend / Full-Stack). Built with modern web technologies, this site features a premium dark-mode aesthetic with glassmorphism, seamless smooth scrolling, and dynamic on-scroll animations.

## Technology Stack
- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Vanilla CSS (Premium Dark Theme & Glassmorphism)
- **Animations:** Framer Motion, React Scroll Parallax
- **Smooth Scrolling:** Lenis
- **Icons & Typography:** React Icons, react-type-animation, Google Fonts (Inter, JetBrains Mono)
- **Deployment:** Vercel (Recommended)

## Key Features
- **Immersive Design:** Deep navy to slate color palette with cyan accents.
- **Advanced Animations:** Parallax backgrounds, staggered reveals, and typing effects.
- **Fully Responsive:** Adapts flawlessly to mobile (375px), tablet (768px), and desktop (1280px) screens.
- **Accessibility Optimized:** Respects `prefers-reduced-motion` system settings.
- **Performance:** Optimized for high Lighthouse scores.

## Local Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/raghavendra2006/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   Ensure you have Node.js installed, then run:
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **View in browser:**
   Open your browser and navigate to `http://localhost:5173`.
